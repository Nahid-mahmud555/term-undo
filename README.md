#  Term Undo

**Eliminate terminal error spam and instantly restore lost command buffers** without breaking Kali Linux's two-line Zsh prompt or losing your command history.

Term Undo aims to make terminal command recovery simpler, faster, and more convenient.

---

##  One-Line Instant Installation

Install Term Undo with a single command.

**Supported environments:**
-  Kali Linux
-  Native Linux
-  Windows WSL
-  Normal User and Root Mode

### Installation

Run the following command in your Zsh terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/nahid-mahmud555/term-undo/main/install.sh | bash
```

Then reload your Zsh configuration:

```bash
source ~/.zshrc
```

---

##  Key Goals

- **Instant Command Recovery** — Restore lost command input quickly.
- **Cleaner Terminal Experience** — Reduce unnecessary terminal clutter during command recovery.
- **Zsh Compatibility** — Preserve Kali Linux's familiar two-line terminal prompt.
- **History Preservation** — Keep your existing Zsh command history intact.
- **Simple Installation** — Get started with a single installation command.
